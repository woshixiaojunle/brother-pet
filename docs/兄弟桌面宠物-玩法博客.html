把同事变成桌面上
爬来爬去的「猴子」？

这个叫 Brother Pet 的小工具，真的做到了 🐵

想象一下：你正盯着 Excel 加班，屏幕角落里突然爬出一只「猴子」——长着你好哥们的脸，戴着他那副黑框眼镜，正沿着浏览器窗口的边沿往上爬。点一下右键，它还会理直气壮地弹出对话框：「叫爸爸！」。

这不是 P 图，也不是动画短片。这是一个能一键打包、发给朋友双击就跑的桌面宠物生成器。今天这篇就带你从「是什么」玩到「怎么整活」。

🎮它到底能干嘛

🐵

多宠物全屏爬行

透明置顶的小窗，多个「猴子」在整个屏幕上自由爬行、跳跃、玩耍。

🪟

窗口边缘即平台

自动扫描桌面窗口，把每个窗口顶面当可站 / 可攀爬的平台，宠物会顺边沿爬上去。

🎞️

支持 GIF 动图

每个动作都能用 GIF，运行时按原生节奏逐帧播放，比静态图生动太多。

🖱️

右键「叫爸爸」

点一下，最近的宠物弹对话框，随机甩一句台词，整活效果拉满。

🚀三步上手，零代码

1
启动前后端。后端默认跑在 8996，前端跑在 5173： 
cd backend && python -m uvicorn server:app --port 8996
cd frontend && npm run dev
然后浏览器打开 http://localhost:5173。
2
选素材、调参数。给「爬行 / 攀爬 / 发呆 / 开心」四个动作分别挑图——示例里已经备好 AI 生成的 GIF（爬行 / 攀爬 / 开心 / 跳跃），直接选就能用；也可以上传自己的图。选 GIF 时右侧会实时预览动画。再填几句「叫爸爸」台词和投喂文案。
3
一键生成 exe。指定输出路径 → 点「生成 exe」→ 等进度条走完 → 下载 → 双击运行。搞定，你的朋友已经在屏幕上爬了。

🥚两个隐藏彩蛋

💩 右键「投喂」

屏幕顶端会掉下几坨 💩 砸向宠物，被砸中的宠物立刻切换成开心蹦跶动画，并弹出「感谢爸爸投喂！」。摸鱼时的快乐，往往就是这么朴实无华。

🗣️ 右键「叫爸爸」

离鼠标最近的宠物会弹对话框，从你预设的台词池里随机抽一句——「叫爸爸！」「爸爸抱抱~」随你发挥。建议把公司群里的经典语录塞进去。

📦发给朋友？一行命令都不用

生成的 exe 是 PyInstaller 单文件：所有素材、配置、Python 运行环境全都内联在里面。直接把 BrotherPet.exe 发到别的 Windows 电脑，对方双击就能跑——不用装 Python，不用带文件夹，也不用联网。

温馨提示：
• 仅支持 Windows 10 / 11（依赖 Win32 API 与 tkinter 置顶窗口）。
• 首次运行可能被 Defender / 管家误报拦截，点「仍要运行」即可——这是 PyInstaller 打包的通病，不是病毒。
• 第一次启动会慢几秒（要先解包到临时目录），之后就丝滑了。

🧩想玩更花？进阶思路

不想只用示例素材？有几个骚操作：

• 自己拍一段朋友爬行的视频，抽帧做成 GIF 丢进去，宠物就是他本人真·在爬。
• 用 generated-gifs/ 里 AI 生成的 61 帧高清 GIF（爬行 / 攀爬 / 开心 / 跳跃）当动作素材。
• 直接改 config.json 调爬行速度、跳跃频率、发呆概率，调出最欠揍的节奏。
