# Brother Pet 桌面宠物 · 玩法全指南

> 把真人照片变成「像猴子一样在桌面上爬行玩耍」的桌面宠物，并一键打包成可分享的 `.exe`。

---

## 一、这是什么

Brother Pet 是一个**桌面宠物生成器**：你上传一张朋友 / 同事的照片，它就能在 Windows 桌面上把这个人变成一只「猴子」，全屏爬来爬去、跳上跳下、挂在窗口边缘晃悠。右键还能「叫爸爸」、能「投喂」💩——一个纯粹用来整活和摸鱼的小玩意儿。

它提供了 **Vue3 前端（可视化配置）+ Python / FastAPI 后端（打包流水线）**。你基本不用写代码：前端选好素材和参数，点一下就生成可双击运行的 exe。

---

## 二、核心玩法

| 玩法 | 说明 |
|------|------|
| 🐵 多宠物全屏爬行 | 透明置顶的小窗，多个「猴子」在整块屏幕上自由爬行、跳跃、玩耍 |
| 🪟 窗口边缘即平台 | 程序扫描桌面上所有应用窗口，把每个窗口的**顶面**当成可站、可攀爬的平台——宠物会顺着窗口边沿爬上去 |
| 🎞️ GIF 动图支持 | 每个动作都能用 GIF，运行时按原生节奏逐帧播放，比静态图生动太多 |
| 🖱️ 右键「叫爸爸」 | 点一下，最近的宠物弹出对话框，随机甩一句台词（「叫爸爸！」「爸爸抱抱~」） |
| 💩 右键「投喂」彩蛋 | 屏幕顶部掉下 💩 砸中宠物，宠物立刻开心蹦跶，弹出「感谢爸爸投喂！」 |

## 三、三种使用姿势

### 姿势一：懒人版 —— 直接拿做好的 exe

如果你只是想玩，把 `gen_tasks/fixed/BrotherPet.exe`（或朋友发来的 exe）双击打开就行。所有素材、配置、运行环境全都内联进 exe 了，无需安装、无需联网。

> 仅限 Windows 10 / 11。

### 姿势二：可视化生成 —— 用前端做个专属宠物

```bash
# 1. 启动后端（默认 127.0.0.1:8996）
cd backend
pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8996

# 2. 启动前端（默认 127.0.0.1:5173）
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`：

1. 添加 / 删除宠物，给「爬行 / 攀爬 / 发呆 / 开心」四个动作分别选素材
   - 示例素材目录 `generated-gifs/` 里已经有 AI 生成的 GIF（爬行 / 攀爬 / 开心 / 跳跃），直接选就能用
   - 也可以上传自己的 PNG / GIF（透明背景最佳）
2. 选 GIF 时右侧会**实时预览动画**，确认效果再生成
3. 调整爬行速度、跳跃频率、发呆频率
4. 填写「叫爸爸」台词池与「投喂」文案
5. 指定输出 exe 路径（如 `D:\brother-pet\BrotherPet.exe`）
6. 点「生成 exe」，等进度条走完，下载即可双击运行

### 姿势三：进阶自定义 —— 换素材玩出花

- 用 `generated-gifs/` 里 AI 生成的 61 帧 GIF（爬行 / 攀爬 / 开心 / 跳跃）当动作素材
- 自己拍一段朋友爬行的视频，抽帧做成 GIF 丢进去
- 直接改 `config.json` 里的参数，调出更骚的爬行节奏（速度 / 跳跃频率 / 发呆概率）

---

## 四、素材怎么准备

- 一张**正面、清晰、半身**的照片，保留发型、服饰特征最合适
- 背景越干净越好（透明背景 PNG 最佳），程序会把人物干净地浮在桌面上
- 想要更生动：**优先用 GIF**，每个动作一段循环动画

---

## 五、注意事项

- ⚠️ **仅支持 Windows**：运行时依赖 `ctypes` 调 Win32 API 与 `tkinter` 透明置顶窗口，macOS / Linux 跑不了
- 🛡️ **杀软误报**：首次运行 exe 可能被 Defender / 360 / 电脑管家拦截，点「仍要运行」即可（PyInstaller 单文件打包的通病）
- 📦 **单文件分发**：exe 发到别的 Windows 电脑直接双击就能跑，不用带文件夹、不用装 Python
- 🐢 **首次启动略慢**：`--onefile` 模式每次要先解包到临时目录，第一次会卡几秒，之后就快了

## 六、技术小科普（给好奇的同学）

整套链路长这样：

```
Vue3 前端 (5173)  ──config + 素材──▶  FastAPI 后端 (8996)
                                          │  build_exe()
                                          ▼
                                  PyInstaller 打包
                                  pet_runtime.py + assets + config.json
                                          │
                                          ▼
                                  BrotherPet.exe（透明置顶桌面宠物）
```

- 前端：Vue 3 + Vite，负责可视化配置和进度展示
- 后端：FastAPI + Uvicorn，调用 PyInstaller 把**运行时 + 素材 + 配置**打包成单文件 exe
- 运行时：`tkinter` 做透明置顶窗，`ctypes` 调 Win32 API 枚举桌面窗口、把窗口顶面当平台，`Pillow` 处理帧动画（GIF 按原生帧时长逐帧播放）
